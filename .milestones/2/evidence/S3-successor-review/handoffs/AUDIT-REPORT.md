### I-01 — the frozen measurement drivers cannot implement the advertised sequence

1. **All eight patch files have inconsistent unified-diff hunk lengths.** Each declares seven old and seven new lines, but its body supplies fewer. `evidence/diff-structure.json` records every file/hash and the counted context/removal/addition lines: FOLD 6/6, INTEGRATION 5/5, VALIDATE 6/6, VOTEFOLD 4/4, VOTESTATE 6/6, VOTEVAL 5/5, RSTATE 3/3. KSTATE has three prefixed lines per side plus two bare blank lines; even granting those blanks as context yields five rather than seven. The scripts use ordinary `git apply`, without recount, at line 23. These are malformed input records before any theorem can be tested. This was established by parsing the frozen patch text, without applying a patch. No compiler-failure credit is claimed.
2. **M09 rejects its own input before Lean.** `instruments/check.sh:14` rejects any `#eval` substring. `instruments/Check.lean:5,8` contain that substring in comments. The intended proposition at line 9 is fully qualified and uses `by decide`, but the shell guard does not parse comments. Independently, `check.sh:7` sets `/tmp/reactivegas/ms2-measure-scratch`, whereas the registry and other drivers use `/tmp/reactivegas-ms2-measure-scratch`.
3. **Successful commands produce failed wrapper exits.** `cold.sh:35`, `replay-build.sh:25`, and `replay-run-green.sh:35` end with `[ "$C" -ne 0 ] && { ...; }` (C2 for replay). When the underlying command succeeds, that final AND-list returns status 1. `check.sh:28` similarly returns 1 for the promised empty stdout if its earlier defects were absent. These are shell-semantics deductions, not executions. The underlying `.exit` receipt can therefore say 0 while the wrapper exits 1. No frozen scheduler resolves that discrepancy.
4. **M13–M15 have no executable batch implementation.** `batch-plan.sh:11–23` prints protocol text and two diff hashes; it does not apply, build, time or restore. The other scripts hardcode the ordinary measurement scratch and ordinary output prefixes; they cannot implement the three batch roots by passing parameters. `restore.sh` accepts target/prefix but hardcodes scratch. The complete `instruments/` inventory supplies no other batch driver. D-01 is confirmed (its wording omits the harmless `pwd` command substitution).

Limit/control: no patch application or shell measurement was run. A static-valid patch set, internally consistent driver/input bindings, and a separately authorized frozen-driver execution would settle reachability; none is supplied by a successful JSON-validator run.
