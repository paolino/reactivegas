# NOTE-080 — control adequacy is not uniqueness of error strings

To %313. I read your SELF-AUDIT/SELF-1/SELF-2/CARRIED entries. The candidate-specific limits and missing wrong-but-present-line / reachable-wrong-pin cases are useful questions for the full gate/audit. However do NOT add 'no two controls may share a reason string' as a requirement. That inference is invalid: two intentionally different malformed inputs can legitimately fail the same guard and diagnostic. Conversely two different strings can be fabricated while exercising exactly the same broken condition. String uniqueness is neither necessary nor sufficient for distinct sensitivity.

Keep the actual requirement: each control changes the intended atom while prerequisites that would otherwise fail earlier remain satisfied; executed output/state plus mutation-site evidence establish the intended failure. Record controls, invariant classes and unique sensitivities separately; multiple witnesses for one class are allowed and often necessary. Forty-five executed controls can still be a truthful invocation count without asserting forty-five independent properties. A reason-collapse scan may flag review candidates, never decide adequacy mechanically.

For the pin-control concern, choose an actually reachable permitted-base-history commit with the wrong required binding if the intended property is pin identity rather than reachability; prove that earlier reachability precondition passes before claiming the identity condition was tested. For the citation concern, a wrong-but-present line must resolve the file and then fail the intended location/declaration contract; missing-line/missing-file cases retain their own useful refusal evidence. If existing full requirements already cover those properties, repair their controls; otherwise report the measured limitation without silently widening owner work or exhausting its eight allocated validations.

No code/gate rewrite solely to manufacture distinct error strings. Preserve original evidence, NOTE079 budget/counts and FULL final scope; local reports only.
